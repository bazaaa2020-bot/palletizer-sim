# Тренажёр РТК паллетизации

Интерактивный тренажёр роботизированной ячейки паллетизации: собираете ячейку в
конфигураторе, тренажёр считает укладку, захват, досягаемость, такт и производительность,
выдаёт состав АСУ ТП со списком сигналов, описывает алгоритм работы обычным языком и даёт
управлять ячейкой с пульта — на плане и в 3D.

## Быстрый старт

```bash
npm install
npm run build          # соберёт dist/palletizer-sim.html
npm run serve          # откройте http://localhost:8080
```

Либо просто откройте `dist/palletizer-sim.html` двойным щелчком — файл самодостаточный
(из внешнего только three.js с cdnjs и шрифт Google Fonts; без интернета 3D-вид
отключается, остальное работает).

## Вкладки

- **Симуляция** — план ячейки, пульт (Пуск/Стоп/Сброс/аварийный стоп), состояния PackML,
  шаги GRAFCET, живые входы-выходы, панель приводов, отказы, обмен паллет.
- **3D-вид** — та же симуляция в объёме: робот, конвейер, паллеты со слоями, тележки, люди.
- **Конфигуратор** — роботы, захват, коробки и схема укладки, конвейеры и подача,
  прокладочные листы, обмен паллет, безопасность, подбор оптимальной конфигурации,
  планировщик артикулов.
- **Алгоритм работы** — описание собранного комплекса человеческим языком.
- **Архитектура АСУ ТП** — структурная схема, спецификация, список сигналов, пояснения.
- **Задания и справочник** — 17 учебных заданий с автопроверкой, глоссарий, нормы.

## Структура

```
src/     исходные части (правим здесь)
build.js сборка src → dist
dist/    собранный самодостаточный HTML
test/    дымовой тест в jsdom
docs/    методика расчётов и план развития
```

## Нормы, на которые опирается модель

ГОСТ Р ИСО 12100, 13849-1/-2, 10218-1/-2, ISO/TS 15066, ГОСТ Р МЭК 60204-1,
ISO 13855, 13857, 14119, 14120, EN 415-4, ISO 3691-4, ISA-TR88.00.02 (PackML),
МЭК 60848 (GRAFCET), МЭК 61131-3, МЭК 61439-1.
