# План развития

## Ближайшее

1. **Группы захвата по форме слоя.** Сейчас группа для многозахвата — только ряд коробок
   одной ориентации вплотную. В реальных оценках (REDCARGO PRO130) слой из 14 коробок
   берётся за 4 цикла группами разной формы (4+4+2+4) с перестроением захвата.
   Нужно: подбор групп по геометрии слоя, захват с регулируемым шагом зон, учёт времени
   перестроения. Это главный источник расхождения с заводской методикой (6,7 против
   4,5 циклов/мин на М5П).
2. **Расчёт Performance Level по ISO 13849-1.** Категория, MTTFd, DCavg, CCF по блокам
   цепи безопасности (стоп → КБ → STO/контактор), проверка достижения PL r из оценки
   риска. По духу — упрощённая SISTEMA внутри тренажёра.
3. **Экспорт спецификации и списка сигналов** в CSV/XLSX для вставки в ТКП и проект.

## Дальше

4. **Редактор логики ПЛК**: GRAFCET/PackML — рисуем шаги и переходы, тренажёр исполняет
   их вместо зашитой последовательности; сравнение своей логики с эталонной.
5. **Шаблон оценки риска по ISO 12100** с привязкой к конкретным опасностям этой ячейки.
6. **Смешанные паллеты** (несколько артикулов на одной паллете), рецепты укладки.
7. **Сценарии тревог для оператора**: серия отказов подряд, учёт простоев Held/Suspended,
   OEE за смену.
8. **Экономика**: стоимость варианта, срок окупаемости против ручной паллетизации.
